# Rede Social de Escritor

Este é um projeto Android desenvolvido com Jetpack Compose.

## Pré-requisitos

Antes de começar, certifique-se de ter o seguinte instalado:
- [Android Studio](https://developer.android.com/studio) (versão Ladybug ou superior recomendada)
- JDK 11 ou superior
- SDK do Android (API level 35 instalada)

## Como rodar o projeto

1. **Clonar o repositório:**
   ```bash
   git clone <url-do-repositorio>
   ```
   (Ou baixe e extraia o arquivo ZIP do projeto).

2. **Abrir no Android Studio:**
   - Abra o Android Studio.
   - Selecione **File > Open**.
   - Navegue até a pasta `rede-social-de-escritor-master1` e clique em **OK**.

3. **Sincronizar o Gradle:**
   - O Android Studio deve iniciar automaticamente a sincronização do Gradle. Aguarde a conclusão do processo.

4. **Executar o aplicativo:**
   - Conecte um dispositivo físico Android com a Depuração USB ativada ou inicie um Emulador.
   - Clique no botão **Run** (ícone de play verde) na barra de ferramentas superior ou pressione `Shift + F10`.

## Configurações do Projeto

- **Min SDK:** 24
- **Target SDK:** 35
- **Linguagem:** Kotlin
- **UI Framework:** Jetpack Compose

## Estrutura do Projeto

- `app/`: Contém o código fonte principal e recursos do aplicativo.
- `build.gradle.kts`: Configurações de build do projeto e do módulo.
